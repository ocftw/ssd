# 延伸閱讀

這裡會定期發布教材的補充說明、實作筆記、最新資安新聞解讀與工作坊公告。文章主要面向以下三類讀者：

- **公民團體成員**：把日常工作中會遇到的資安情境寫成可以照做的步驟。
- **組織管理者與顧問**：分享在組織內推動資安改善時的方法、權限矩陣等實作經驗。
- **零基礎讀者**：補上單一主題的入門背景，讓教材的設定步驟更好理解。

文章採用分類標籤（如「教學」、「組織管理者」、「顧問帶領情境」），可在每篇開頭看到「適用對象」的標示。如果你還在摸索目前的資安狀態適合從哪裡開始，建議先從 [怎麼升級資安？](https://ssd.ocf.tw/how-to/index.html) 入口出發，再回過頭看延伸閱讀。
