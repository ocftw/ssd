# 寫作原則

1. 預設讀者是國中生，且對於資安的知識非常微薄。我們的主題是「資安防護新手村」，可以用出去冒險常見的道具（例：書包、寶藏箱、盾、升級裝備）等方式來做舉例。
2. 一定要給做法建議，不要只給予觀念、或是設定方式但不說明要設定成什麼，要告訴讀者「請設定成ＯＯＯＯ」、「請用這個工具」、「請買那個」。
    - 不要這樣寫：權限設定很重要！你可以在手機的「設定」裡調整！
    - 要這樣寫：權限設定很重要，建議把「位置」、「相機」、「麥克風」的權限，都調整成「每次詢問」。避免應用程式預設取得過多的權限。
3. 不列入任何概念有關於技術的知識，例：加密通訊的原理、Android是開源的東西。這些知識最後將會寫成文章，供有興趣的讀者當延伸閱讀。若在整理文案時有看到值得寫成文章的技術知識，請另外列表整理
4. 文案力求精簡，不用特地為了硬是要列點三項東西而多講廢話。要是只有一個重點，那就是只有一個重點，寫一個就好。尤其是「可以增強的防護力」，簡單舉例就好。
5. 文案會有幾種類型：
    - 軟體設定類型的操作說明：
        - 這邊注重在說明「要設定成什麼樣子」，跟為什麼要這樣設定。
        - 操作說明點到就好，讀者只要知道大致上的設定位置，應該就可以自行操作了。
        - 因為系統可能在更新後，改變了設定方式，所以請加上但書並附上官方的說明。例：設定方式可能因系統版本不同而有所差異，更多設定說明，可參考[官方「設定指紋」說明](https://support.google.com/googlepixeltablet/answer/13554937?sjid=13219202813424791687-NC#zippy=%2Cadd-a-fingerprint)。
    - 數位工具推薦：
        - 這邊注重在推薦特定幾個不同（甚至可能只有推薦一個）的數位工具服務，例：密碼管理器可以用 1password、VPN 可以用 Shark、通訊軟體用 Signal 等等。
        - 同一個服務，不同的提供者的訂閱費用可能不一樣，請在「所需金錢預算」裡寫「服務訂閱費」，再提供一個數字範圍即可。
        - 因為還是希望讀者為了自己選擇哪個數位工具負責，我們雖然有建議的工具但無法完全背書，所以請在「知識簡介」裡特別提到這是我們的建議，若有需要市面上也有其他類似的數位工具，若有興趣可以多探索。
    - 物件購買建議：
        - 這邊注重在推薦不同的產品類型跟挑選要注意的地方，（例如：防窺片是包覆在螢幕外層的東西，可能是一層貼膜也可是可拆卸的塑膠片，可以防止別人從旁看到自己裝置螢幕內容的東西，挑選時要注意尺寸跟自己的裝置合不合。）
        - 除非是比較冷門的物件，不用特別介紹特定品牌的產品。像是 USB 安全金鑰這種比較不常見的物件，倒是可以提供幾個推薦品牌當參考。
        - 「所需金錢預算」裡寫數字範圍即可。
    - 制度建立建議：
        - 這邊注重告訴管理組織的讀者要怎麼建立一些流程制度，但不只要跟他們說建立制度的重要性，還要給予「建立什麼樣的制度」的建議
            - 不要這樣寫：要定期盤點裝置/作業系統，這樣才能隨時掌握組織內裝置的狀態。
            - 要這樣寫：建議每3個月盤點一次組織所有的裝置/作業系統，盤點時，至少需要紀錄ＯＯＯ、ＯＯＯ、ＯＯＯ項目。
        - 各組織可以按照自己的需求建立紀錄用的文件，但我們也提供一個模板讓大家參考。可寫在操作的最後一步：若有需要，可以參考「資安紀錄模板」建立組織內部紀錄。
