# 陪伴模式：現況盤點

## 說明

透過正式訪談和非正式對話與員工接觸，以識別組織在採納新的數位和實體安全實踐方面的優勢和弱點（包括專業知識、資金、學習意願、員工時間等）。稽核員會利用這些資訊來相應地調整稽核範圍和建議事項。

## 目的

了解一個組織的優勢和弱點能讓稽核員提供更客製化的建議，而這些建議將是該組織更有可能嘗試並達成的。稽核員將在準備稽核本身時以及評估某項建議的難易度時，使用這項評估結果。此資訊也提供了一個起點，用來了解組織目前對技術、數位安全及當前威脅情勢的使用和理解，同時也能揭示組織工作流程、基礎設施，甚至是您原本可能忽略的漏洞等要素。
