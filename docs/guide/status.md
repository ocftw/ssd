# 幫助組織盤點現況

不同組織在人力、預算、技術熟悉度與工作型態上的條件差很多。若未先掌握現況，稽核範圍與建議容易脫離組織真正能執行的範圍。現況盤點透過問卷、訪談與必要的辦公、設備勘查，辨識組織在導入數位與實體安全實務上的優勢與缺口（例如：專業知識、可運用時間、學習意願等）。稽核員依此調整稽核深度與建議優先順序，並在準備稽核與評估各項建議的可行難度時持續參考盤點結果，讓後續建議較貼近組織敘事、較可能被採納。

## 基本步驟

1. **蒐集背景與工作方式**：依問卷與訪綱（[見參考文件](#reference)）整理組織任務、流程、敏感資料與對外接觸型態，作為後續討論的共同語言。
2. **進行訪談與對話**：與關鍵成員進行正式訪談與必要時的非正式對話，補齊問卷無法呈現的脈絡與實際作法。
3. **視需要辦理設備與空間勘查**：在組織同意且風險可控的前提下，以盤點表單（[見參考文件](#reference)）掌握主要裝置、帳號使用方式與實體環境概況。
4. **彙整盤點結論**：歸納優勢、缺口與待釐清項目，作為威脅建模、改善建議與稽核範圍調整的輸入。

## 執行建議

- 先從工作流程與資料流開始盤點，再談工具或設定。先理解組織如何工作，再對應到技術與控制措施，建議才會落在可執行範圍內。
- 假設每個組織面對的威脅與壓力來源都不同，並依組織的倡議主題、合作對象與資料類型調整問卷與訪談重點，盤點結果才足以支撐後續風險判斷。
- 先收斂出少數（例如：三至五項）最影響業務連續性或資料保護的缺口優先追問。項目過多時組織難以聚焦，也會稀釋後續改善的動能。
- 讓組織成員成為描述現況與界定問題的主體。稽核員負責結構化提問與記錄，若只有顧問單方面判讀，建議往往難以在稽核結束後延續。

## 注意事項

- 確保任何實體筆記、圖稿在數位記錄完成後立即擦除並銷毀。
- 確保此過程的任何數位記錄（含錄音、錄影、訪談逐字稿、盤點照片）都受到適當的存取控管與加密保護。
- 考量進行訪談與勘查的空間。確認誰可以進出、監視錄影是否涵蓋討論內容，以及若活動跨日或隔夜，該空間是否有門鎖或門禁管制。
