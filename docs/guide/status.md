# 幫助組織了解資安現況

在協助組織改善資安前，先透過訪談、問卷和場勘了解現況，像是曾遭遇的攻擊、帳號與檔案管理方式、成員資安習慣，以及辦公室和機房環境。這能幫助組織找出真正需要優先處理的問題，讓後續改善更符合實際需求。

## 基本步驟

1. **訪談**：依照訪談大綱（[見參考文件](#reference)）訪談資安負責人，或是熟悉組織數位環境的人員，了解組織規模、資安人力、過去是否受過攻擊、是否有資安訓練經驗，以及目前帳號和檔案的管理方式。
2. **問卷調查**：利用問卷（[見參考文件](#reference)）了解組織成員對資安的認識，以及平常如何使用帳號、管理檔案與裝置等。
3. **辦公室勘查**：利用場勘記錄表（[見參考文件](#reference)）了解辦公室環境、機房或網路設備放置位置，以及是否有需要改善的實體安全問題。

## 執行建議

- 每個組織面對的威脅來源都不同，可以適時調整問卷與訪談重點。
- 可以讓熟悉日常工作的成員一起參與訪談，因為資安主責人通常了解管理方式，但實際的帳號使用、檔案分享和工具使用情況，常常需要透過一線成員才看得清楚。

## 注意事項

- 慎選進行訪談的空間，確認誰可以進出、監視錄影是否會紀錄下訪談內容，並確認該空間是否有門鎖或門禁管制。
- 訪談紀錄、問卷結果和場勘記錄表可能包含組織內部流程、設備位置和資安弱點，應設定存取權限，並限制只有必要人員可以查看。
