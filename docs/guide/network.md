# 陪伴模式：網路使用行為

## 說明

關注在瀏覽器使用、隱私保護（廣告追蹤）、釣魚信、VPN 使用、WiFi 基本。

## 目的

- 了解瀏覽器的隱私問題，私人與公務混用可能意外暴露公務內容或屬性。
- 釣魚信件的判斷。
- VPN 原理、使用情境。
- WiFi 連線基本原理。

## 注意事項

- 大部分都使用 Chrome 的瀏覽器，可以改用 Brave 或 LibreWolf，套件都可以通用，改用非 Chrome 主要是隱私考量。
- VPN 使用建議都選擇當地伺服器的主機，避免造成連線行為太獨特。

## 產出

- 請依教材建議安裝相關的瀏覽器套件，提升隱私防護能力。
