# 身份驗證與憑證強化

在完成[工作帳號盤點](account.md)後，下一步是把登入習慣調整到可長期維持的強度。身份驗證與憑證強化聚焦於密碼品質、多因子驗證與密碼管理器的導入，目標是降低共用密碼、重複密碼與單一因子被釣魚後整組淪陷的風險。這些措施與盤點清單搭配時，較能對應到具體服務與負責人，而不是抽象口號。

## 基本步驟

1. **檢視各服務的密碼與回復設定**：確認是否仍使用預設或易猜測密碼、回復信箱是否仍有效。檢核重點見（[見參考文件](#reference)）。
2. **為關鍵服務啟用多因子驗證**：優先處理具管理權限或存取敏感資料的帳號。建議優先序與設定提示見（[見參考文件](#reference)）。
3. **導入密碼管理器並調整共用習慣**：以可負擔的方式讓成員把常用服務納入管理器，逐步減少通訊軟體或試算表傳遞密碼。導入節奏見（[見參考文件](#reference)）。
4. **處理清單中標記為閒置或高風險的帳號**：停用不再需要的帳號，或將共用帳號改為個人身分加權限模型。與盤點結論的對照方式見（[見參考文件](#reference)）。

## 執行建議

- 先從已盤點出的高權限、高曝露帳號開始要求 2FA，再擴及一般成員。漸進式要求較容易維持採用率。
- 推廣多因子驗證時，優先選擇非簡訊通道（例如：驗證器應用程式、安全金鑰）。簡訊通道在部分情境下較易受攔截或轉移攻擊。
- 給予密碼管理器試用與練習期（例如：一個月），先從低風險帳號建立習慣。降低心理門檻能提高持續使用率。
- 讓各部門自行分擔帳號健檢與回報。分散式參與能發現中央盤點時遺漏的服務。

## 注意事項

- 2FA 常稱為二階段驗證，MFA 常稱為多因子驗證。對外溝通時可固定用語，避免成員混淆。
- 盤點中標記為不再使用的帳號，請採取停用或更改強密碼並啟用 2FA 後再封存紀錄。
- 密碼管理器的主密碼與回復金鑰應獨立保存，並限制能接觸匯出檔的人員。
