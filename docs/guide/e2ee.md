# 陪伴模式：加密通訊

## 說明

瞭解即時通訊的端到端加密、驗證彼此的安全碼，郵件加密的流程與通訊加密的使用情境。

## 目的

- 瞭解什麼是端到端加密，確保訊息無法被服務商閱讀。
- 瞭解郵件加密技術或加密原理。
- 與公務相關或高度機敏資訊傳遞交流時，要使用加密相關的通訊軟體與服務。

## 注意事項

- 解釋加密流程或技術時會有門檻，建議可以透過圖片或是影片的方式播放介紹，不一定要自己來完成這個技術的解釋。
- 如有使用到 ProtonMail 服務，也請再次提醒當非為 ProtonMail 的信件互相寄送時，郵件皆為非加密內容。
- 如有使用 Signal，請帶領學員完成驗證安全碼。

## 產出

- 如有使用 Signal，完成驗證安全碼。
- 如有使用 Mailvelope，完成加密郵件的設定與寄送。
