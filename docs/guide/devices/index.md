# 盤點組織裝置設備

遭入侵的裝置往往能繞過組織在其他層面做的防護，因此裝置盤點是改善計畫中不可缺的一環。裝置盤點在此階段的重點，在於辨識會接觸公務資料的電腦與行動裝置，確認作業系統與關鍵軟體的更新狀態、是否具備基本惡意程式防護，以及登入身分與加密等設定是否符合組織政策。盤點結果應能回饋到優先修補項目與後續教育主題。

## 基本步驟

1. **界定盤點範圍與資產邊界**：列出應納入的裝置類型（例如：辦公桌機、筆電、手機）與是否含個人自攜設備。範圍說明見（[見參考文件](#reference)）。
2. **蒐集裝置與負責人對應關係**：建立資產與使用者的對照，並標註主要用途（例如：財務、對外聯絡）。表單範本見（[見參考文件](#reference)）。
3. **執行安全狀態檢查**：依組織政策檢視系統更新、防護軟體、磁碟加密與登入帳號歸屬等項目。檢查面向見（[見參考文件](#reference)）。
4. **彙整缺口與追蹤修補**：將異常裝置列入待辦並指定結案期限，必要時安排複查或現場協助。與[裝置檢查活動](checklists.md)的銜接方式見（[見參考文件](#reference)）。

## 執行建議

- 先聚焦會處理敏感或對外代表組織的裝置，再擴及其他設備。範圍收斂，較容易在短時間內看到修補成效。
- 盤點過程以參與者自行操作為原則，稽核員或帶領者僅在同意下代為操作。尊重與透明，能降低對「被檢查」的排斥。
- 對異常狀況訂出明確後續期限（例如：一週內通報、兩週內修補）。有期限，清單才不會淪為一次性報告。
- 將檢查表與教育教材連結，讓成員知道如何自行驗證更新與加密是否生效。可重複執行的檢查，才能支撐長期維運。

## 注意事項

- 裝置評估資料與從裝置取得的任何額外資訊，應採嚴格存取控管與加密保存。
- 發現惡意程式感染或疑似大規模外洩時，應依組織通報程序立即處置，而不是僅記錄在盤點表。
- 實體盤點或工作坊場地的進出與監視錄影，應比照其他敏感討論場景管理。
