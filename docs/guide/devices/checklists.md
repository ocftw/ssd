# 陪伴模式：裝置檢查

## 概要

- 確認裝置的登入帳號是否為裝置擁有者的權限。
- 檢查裝置是否有安裝防毒軟體。
- 記錄裝置作業系統版本。
- 確認裝置是否有磁碟加密。

## 是前準備

- 和參與者說明裝置健檢的流程，原則上以有接觸工作資料的裝置為主，並由參與者自行操作裝置，在參與者的同意下，可以由帶領者代為操作裝置。
- 和參與者說明資訊處理原則，主要包含以下兩大原則：裝置中的個人資訊都會被保密，並且不會暴露給管理層知道。
- 說明清楚哪些情況屬於必須立即通報處理，例如：惡意軟體感染、重大資料外洩等。其他一般性的弱點將會不具個人識別性的方式紀錄下來。
- 依照作業系統盤點裝置數量：Windows、MacOS、Android、iOS
- 請參與者在活動前將所有裝置的作業軟體更新到最新版本

## 流程

- 按照作業系統分組，帶領裝置檢查
- 一位紀錄裝置健檢過程、帶領參與者操作裝置
- 建議分組：蘋果產品一組（會以 iOS 先帶），Windows 一組、Android 一組
- 發現異常時一定要採證或是截圖紀錄，待後續通報處理
- 未完整完成裝置檢查的裝置，應該擇日補完成。

## 提示

1. iOS 先帶，可以壓縮 MacOS 的檢查時間
2. Windows 10.11 的介面不同，需要注意；Android 裝置的設定介面也有很大差別，也會影響活動時間
3. 盤點設備時，桌電的數量與位置，可能會影響帶裝置健檢的分組與時間
4. 在裝置上的任何刪除、登出或重置動作，務必與裝置擁有者確認
