# 辦公位置網路建議

<small>預計操作時間：首次盤點與規劃各據點約 0.5–1 天，之後每年檢查 1 次約需數小時</small><br><small>所需預算：視各地點現況而定（可能包含路由器與佈線升級、行動熱點或專線月費、VPN 服務費等）</small>

對公民團體來說，辦公地點不一定只有一個固定的總部：有時是在主要辦公室，有時是在外點據點，有時是在合作機構裡的一小塊座位，甚至是在咖啡廳、共用辦公室或旅館裡臨時打開筆電，因此就算是提升了自身辦公室的網路防護，也不代表提供了全面的防護。

這一篇是寫給負責整體資安與行政的你，目標是幫你釐清「組織實際會在哪些地方工作」、「每種地點至少要做到什麼樣的網路防護」、「什麼情況下一定不要用不安全的網路處理敏感資料」。你可以把這些建議直接改寫成內部指引，或放進出差、場勘表單裡。

!!! benefit "可以增強的防護力"

    - 降低在咖啡廳、旅館、公用 Wi-Fi 等環境處理敏感資料時被攔截的風險
    - 讓總部、分部、外點據點都有清楚的「最低網路安全標準」
    - 幫助事先估算網路相關的預算（設備汰換、行動熱點流量、VPN 服務等）
    - 把「在哪裡可以做什麼、不能做什麼」說清楚，讓同仁有依據可以拒絕不安全的工作要求

## 盤點組織可能需要使用網路的地方

在談標準之前，只要列出幾類常見場景，就能開始一一決定要怎麼搭建防護、搭建到什麼程度。建議你用簡單表格，先列出所有可能的辦公環境：

- **總部、主要辦公室**：組織主要成員日常工作的地方。
- **分部或外點辦公室**：長期有人駐點、但規模較小的辦公空間。
- **長期駐點或合作空間**：例如長期借用合作機構裡的一個座位、常駐在某空間的角落。
- **短期使用空間**：共用辦公室的臨時工位、借用會議室、培訓場地、展覽空間。
- **完全外部的臨時環境**：咖啡廳、旅館大廳、車站或機場休息區等。

針對每一個列出的辦公環境再補充：

- 主要使用的網路來源（自家路由器、空間提供的 Wi-Fi、公用 Wi-Fi 等）。
- 組織是否能控制設備設定（可以自行安裝路由器、要求改設定，還是完全無法掌控）。

這份清單會是後面所有決策的基礎：哪些地方可以要求升級設備、哪些地方只能用行為規範來降低風險。

## 為不同類型的辦公環境訂出最低標準

不是每個地方都能做到同樣的網路防護，但你可以為不同類型的地點訂出「至少要做到什麼」的共通標準。

=== "可控據點"
    
    可控的據點包括總部、分部辦公室等固定的地點，裝備可以慢慢升級，但至少應該做到：

    - 使用由組織自行管理或信任度高的路由器或 AP，而不是長期使用不明來源的共用設備。
    - Wi-Fi 一律有密碼，並採用 WPA2 或 WPA3 加密，不使用「開放 Wi-Fi」。
    - 內部工作用網路與訪客、活動用網路分開，並限制訪客網路不得直接存取內部伺服器。
    - 有人負責定期檢查 Wi-Fi 設定與韌體更新，具體作法可參考「Wi-Fi 設定」。

=== "半可控空間"
    
    半可控空間包括共用辦公室、合作機構裡的一角等。這些地方，多半無法完全控制整體網路，但可以先做到：

    - 與空間提供者確認：Wi-Fi 是否有密碼、加密方式是否至少為 WPA2 或 WPA3、是否有分訪客網路。
    - 若可能，評估是否可以自帶小型路由器接在現場網路上，自行建立一個只給組織成員使用的 Wi-Fi（並自行管理密碼與設定）。
    - 若無法掌控設定，建議在該空間處理敏感資料時，一律改用 VPN 或手機熱點。

=== "完全不可控場所"

    有時候需要臨時在咖啡廳、旅館、公用 Wi-Fi等地方使用網路，是風險最高地方。你可以把這些條列整理成一張簡單的「地點 vs 建議行為」對照表，貼在內部文件或新人訓練教材裡，讓大家一眼就知道在哪裡可以做多少事。：

      - **建議不要做的事**：例如不要在這些網路上登入後台系統、開啟含敏感個案資料或捐款人名單的文件、操作網路銀行或關鍵管理介面。
      - **若真的不得不處理時的底線**：例如優先改用手機熱點，或先連上組織提供的 VPN，再處理僅限必要的工作，並在返回可信任環境後盡快更改重要帳號密碼。


## 居家辦公的網路設定

許多公民團體會讓成員在家或外點長期辦公，這些地方往往不像總部那樣有專人管理，但同樣承載著敏感工作。你可以把以下內容訂成組織對「在家、外點辦公」的最低網路要求：

- **家中或外點的 Wi-Fi 必須有基本防護**

  建議在內部指引裡明寫：

  - 家中或外點的 Wi-Fi 必須設定密碼，且加密方式為 WPA2 或 WPA3。
  - 路由器的管理帳號與密碼需從出廠預設值改成專用強密碼，不與家人或外人隨意分享。
  - 若使用網路設備非常老舊，無法更新韌體或只能使用不安全的加密方式，請成員主動回報，組織可協助評估汰換。

- **與家庭成員共用網路時的注意事項**

  即使網路本身是共用的，仍可透過一些簡單規則降低風險，例如：

  - 不在容易被他人看到螢幕的公共空間處理高度敏感的資料。
  - 不隨意將內部系統網址、共用資料夾連結貼到家人或朋友共用的通訊群組裡。
  - 若有外人臨時借用家中的 Wi-Fi，盡量避免在同一時間處理敏感工作。

- **必要時的支援與補助**

  若你發現有同仁因為經濟或地理因素，難以自行升級路由器或網路環境，可以考慮：

  - 規劃一筆小額預算，用於補助在家辦公同仁更換基本安全的路由器。
  - 在補助前提供簡單的挑選建議（例如支援 WPA2 或 WPA3、有定期韌體更新的品牌），避免只看價格選擇過於老舊的設備。

## 把網路風險納入出差與場勘規劃

當組織成員需要外出培訓、辦活動或出差時，場地的網路品質與安全程度，往往會直接影響工作的順利與風險。你可以在原本的出差或場勘規劃表裡，加上幾個與網路相關的欄位：

- **事先確認場地提供的網路條件**

  在與場地方聯繫時，除了詢問投影設備與座位數量，也一併問：

  - 是否提供有線網路或專用的活動 Wi-Fi。
  - 若有 Wi-Fi，是否有密碼、使用哪一種加密方式、是否有分訪客網路。
  - 是否允許你自帶路由器或行動熱點設備。

- **評估是否需要自備網路與預估費用**

  若場地僅提供公開且不可信任的 Wi-Fi，或無法保證穩定：

  - 評估是否需要自備行動熱點（個人或共用），作為處理關鍵工作時的後備方案。
  - 預估可能的流量與費用，提前列入活動或出差預算，而不是臨時報銷。

- **在場勘或活動流程表中加入「網路檢查」步驟**

  例如在場勘清單裡新增一項：

  - 抵達現場後，實際連線測試場地方提供的網路，確認是否可以順利連上必要的雲端服務。
  - 若發現只能使用公開 Wi-Fi，現場立即決定：哪些操作要延後、哪些改用手機熱點。

你可以直接在既有的場勘範本或出差規劃文件裡，加上「網路環境」這一欄，並附註「如僅提供公開 Wi-Fi，請依組織指引改用手機熱點或調整工作內容」。

## 分工與預算規劃

要讓這些網路建議真的落地，最後需要有人負責彙整資訊、追蹤執行情況，並在年度預算裡預留足夠空間，而不是「壞了才臨時找錢」。你可以這樣安排：

- **指派一位「據點與網路」聯絡窗口**

  這個角色可以與前面「[裝置/作業系統盤點](../devices/audit.md)」或「[Wi-Fi 設定](wifi.md)」裡提到的管理人員合併，由同一個小組負責：

  - 彙整各地點的網路環境盤點表與最低標準達成情況。
  - 與各據點負責人或空間提供者保持聯絡，追蹤網路相關異動。

- **將網路相關需求納入年度預算與資安提升計畫**

  在規劃年度預算時，請特別把以下項目列出來：

  - 路由器與 AP 的汰換或新增預算。
  - 外點或高風險地區需要的行動熱點與流量費。
  - 若有需要，VPN 或安全連線服務的訂閱費。
