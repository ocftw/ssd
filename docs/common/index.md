cards:
  - title: 釣魚、詐騙郵件
    url: common/phishing.html
    description: |
      假冒機構或服務寄來的信件、簡訊，常以帳號異常、補件為由誘導點連結或輸入密碼。辨識寄件來源、不隨意點擊，並透過官方管道查證，可降低受騙與資料外洩風險。
  - title: 勒索軟體
    url: common/ransomware.html
    description: |
      惡意程式會加密檔案或威脅公開資料，要求支付贖金。平時備份、更新系統與留意附件來源有助預防；若已感染，應中斷擴散並依程序通報與復原。
  - title: 帳號密碼外洩
    url: common/leaked_password.html
    description: |
      密碼可能在資料外洩、釣魚或重複使用下被取得。盡快更改密碼、啟用雙重驗證，並檢查帳號異常登入，能減少遭盜用的影響範圍。
  - title: 社群帳號被盜（粉專／LINE）
    url: common/social_account_takeover.html
    description: |
      粉專、LINE 官方帳號或 IG 一旦被盜，攻擊者可能短時間內冒名發詐騙連結、洗版或改掉登入信箱。先發公告止血，依官方申訴流程取回，並清查綁定帳號與管理員清單，能降低對組織信任的衝擊。
  - title: 官網遭受攻擊
    url: common/website_attack.html
    description: |
      網站可能被竄改內容、植入惡意程式或無法連線。平時備份網站與紀錄、限制後台權限；發現異常時保留紀錄、通報並還原乾淨版本。
  - title: NAS 遭受攻擊
    url: common/nas_attack.html
    description: |
      NAS 被入侵時常伴隨檔案加密、不明管理員帳號或國外 IP 登入。平時關閉對外連線、保持韌體更新、強化管理員帳號；發現異常時先斷外網但保留紀錄，再從離線備份還原。
