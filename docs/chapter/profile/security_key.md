# 安全金鑰

<small>預計操作時間：約 30 分鐘（含註冊到常用帳號）</small><br><small>所需預算：約 500–1500 元（視型號與品牌而定）</small>

安全金鑰是外型像隨身碟或小鑰匙的硬體，可插電腦 USB 或用手機 NFC 感應。登入時，在輸入密碼後，系統會要求你插入金鑰或觸碰金鑰按鈕，通過後才算完成登入。因為必須「擁有實體裝置」，駭客無法只靠密碼或網路攻擊取得你的二階段認證。可以準備一把安全金鑰，並在常用且重要的帳號（例如 Google、Microsoft、密碼管理器）中註冊使用。若擔心遺失，可多買一把當備份，兩把都註冊同一帳號，遺失主金鑰時仍可用備份金鑰登入。

!!! benefit "可以增強的防護力"

    - 即使密碼外洩，沒有實體金鑰仍無法登入
    - 降低釣魚或假網站騙走第二因素驗證的風險



## 購買安全金鑰

=== "挑選要點"

    -  **支援的標準**：請選擇支援 FIDO2 或 FIDO U2F 的安全金鑰，多數大型服務（如 Google、Microsoft、Facebook）都支援。
    - **與裝置相容**：確認你的電腦是 USB-A 還是 USB-C、手機會不會用到 NFC，再選對應的型號，避免買了無法使用。
    - **備份金鑰**：若你只有一把金鑰，遺失或損壞後可能無法登入帳號。建議購買兩把，一把日常使用、一把妥善收好當備援，並在重要帳號同時註冊兩把。
    - **妥善保管**：安全金鑰不要借給他人或插在公用電腦上長時間留置，使用完就拔除收好。

=== "品牌參考"

    安全金鑰在一般通路較少見，以下為常見且符合標準的品牌，可作為選購參考，市面上仍有其他符合 FIDO2/FIDO U2F 的產品，可依預算與介面需求自行比較：

    - **YubiKey**：[Yubico 官網](https://yubico.com/){target="_blank"} — 型號多，有 USB-A、USB-C、NFC 等組合，價格約數百至一千多元。
    - **Nitrokey**：[Nitrokey 官網](https://nitrokey.com/){target="_blank"} — 開源硬體設計，提供多種型號，價格約一千元上下。


## 註冊使用

1. 登入要保護的帳號（例如 Google），前往「帳戶」或「安全性」>「兩步驟驗證」或「安全金鑰」相關選項。
2. 選擇「新增安全金鑰」，依畫面指示插入金鑰（或用手機 NFC 感應），並按下金鑰上的按鈕完成註冊。
3. 之後登入時，輸入密碼後系統會提示插入或觸碰安全金鑰，照做即可完成驗證。
4. 各服務的設定路徑可能因改版而不同，可至該服務的說明中心搜尋「安全金鑰」或「兩步驟驗證」取得最新步驟。
