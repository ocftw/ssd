# :material-book-check: 風險評估政策規範

## 政策範本

1. 定期召集組織成員舉行風險評估會議，評估組織目前及未來一年的狀況。組織可依部門或專案進行風險評估，針對高威脅（後果嚴重）及高風險（發生可能性高）的項目提出應對措施。

## 安全建議執行

| 安全檢查   |                  優先等級                  | 說明細節                               |
| ---------- | :----------------------------------------: | -------------------------------------- |
| 風險評估表 | `須知`{style="background-color: #fff2cc;"} | 可參考教材網站的「威脅建模」章節說明。 |
| 評估目標   | `須知`{style="background-color: #fff2cc;"} | 可依組織續存問題、議題推動、內部同仁。 |
