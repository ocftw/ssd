# 瀏覽器

<small>預計操作時間：約 40 分鐘（含選擇與基本設定）</small><br><small>所需預算：無（推薦瀏覽器皆可免費使用）</small>

當要開始使用網路時，點入「瀏覽器」（例如 Safari、Firefox、Chrome 等），我們才能使用各種雲端服務（如 Email、線上表單、雲端協作等）來完成日常工作；瀏覽器若防護不足或過度收集資料，就像門戶沒關好，容易增加風險。慎選注重隱私與安全的瀏覽器，並做好基本設定，能顯著提升防護力。


!!! benefit "可以增強的防護力"

    - 減少被廣告與追蹤器收集瀏覽行為
    - 阻擋惡意與誤導性內容、降低釣魚風險
    - 降低瀏覽資料被業者或第三方收集
    - 透過更新修補已知漏洞，減少暴露於危險環境

## 選擇注重隱私與安全的瀏覽器

「瀏覽器」作為上網的門戶，建議優先選擇注重隱私與安全的產品。以下為我們篩選出、注重隱私且較容易取得的選項，可依需求擇一使用。

=== "LibreWolf"

    **開箱即強化隱私**，適合希望少動手設定、又能兼顧隱私的使用者。

    - 以隱私、安全與使用者自由為目標，預設無遙測與資料收集，內建廣告、追蹤阻擋與強化隱私設定，並隨 Firefox 更新。
    - 適合希望比 Firefox 更省事、一安裝就有較強隱私防護的讀者。預設已強化隱私與安全，可依需要於設定中微調
    - 詳見 [LibreWolf 官網](https://librewolf.net/){target="_blank"}與[功能說明](https://librewolf.net/docs/features){target="_blank"}。

=== "Brave"

    **隱私與效能平衡**，內建廣告阻擋與進階隱私選項。

    - 內建廣告與追蹤阻擋，可提高頁面載入速度並減少被追蹤。
    - 隱私保護程度高，並可選擇使用 Tor 隱私視窗以提升匿名性。
    - 與 Chrome 同一架構，可安裝 Chrome 商店的附加元件使用。

=== "Firefox"

    **擴充彈性高**，適合想自行加裝隱私附加元件的使用者。

    - 預設啟用「[加強型追蹤保護](https://support.mozilla.org/zh-TW/kb/enhanced-tracking-protection-firefox-desktop){target="_blank"}」，可阻擋廣告追蹤與第三方 Cookie。
    - 支援多種隱私保護附加元件（如 uBlock Origin 等），可依需要進一步加強。
    - 提供無痕模式，不保存瀏覽歷史、Cookie 與搜尋紀錄。


=== "Tor 瀏覽器"

    **最強隱私保護**，適合高風險情境（如記者、人權工作者等）。

    - 透過 Tor 網路加密並經多個中繼點轉送流量，可隱藏真實 IP、提高匿名性。
    - 預設阻擋追蹤與部分腳本，完全以隱私為導向。
    - 瀏覽速度通常較一般瀏覽器慢，且部分網站可能限制來自 Tor 的連線；僅在需要高度匿名時建議使用。

## 加強瀏覽器的隱私與安全設定

=== "Firefox"

    開啟 Firefox，點擊右上角選單（三條橫線）>「設定」>「隱私與安全」。

    - **增強追蹤防護**：設為「嚴格」，以阻擋更多追蹤器。
    - **Cookie**：選擇「僅允許原始網站」或「封鎖所有第三方 Cookie」，減少被追蹤。
    - **表單與密碼**：建議取消勾選「記住登入網站的帳號和密碼」與「自動填寫地址」；密碼可改用專門的密碼管理工具。
    - **瀏覽記錄**：選擇「永不記錄瀏覽記錄」，或於「清除歷來記錄」中設為「永不」。
    - **網址列建議**：取消勾選所有建議選項，減少資料外送。
    - **Firefox 資料收集與使用**：取消勾選所有「允許 Firefox …」選項，避免 Mozilla 收集資料。
    - **危險與誤導性內容**：請勾選「阻擋危險與誤導性內容」、「阻擋不受信任來源的軟體」。
    - **關閉地理位置追蹤**：於網址列輸入 `about:config`，搜尋 `geo.enabled` 並設為 `false`。設定方式可能因版本不同而有所差異，更多說明可參考 [Firefox 隱私與安全說明](https://support.mozilla.org/zh-TW/kb/firefox-privacy-and-security-settings){target="_blank"}。


=== "Brave"

點擊右上角選單（三條橫線）>「設定」>「防護」或「隱私權與安全性」。

- **Shields**：保持開啟，阻擋廣告與追蹤器。
- **追蹤與廣告**：選擇「標準」或「嚴格」。
- **升級連線至 HTTPS**：建議設為「嚴格」。
- **指紋防護**：啟用。
- **Cookie**：選擇「封鎖第三方 cookies」。
- **搜尋引擎**：於「設定」>「搜尋引擎」中，將預設搜尋改為 DuckDuckGo 或其他隱私導向的搜尋引擎。
- **清除瀏覽資料**：於「隱私權與安全性」>「清除瀏覽資料」中，可設定離開時自動清除瀏覽歷史、Cookies 與快取。
- **網站權限**：於「網站與 Shields 設定」中，將「位置」、「攝影機」、「麥克風」設為「詢問」，「通知」設為「阻止」。


## 保持瀏覽器更新

瀏覽器多會在背景自動更新，但**往往需要重新啟動**才算完成安裝。當瀏覽器提醒需要重新啟動時，請儘快重啟，以套用最新安全修補，避免暴露於已知漏洞。
