# 網路使用行為政策規範

## 政策規範

1. 使用注重隱私的瀏覽器，如 Firefox、LibreWolf 或 Brave，搭配 uBlock Origin 套件以阻擋廣告追蹤。
2. 使用注重隱私的搜尋引擎，如 Brave Search、DuckDuckGo、SearXNG 或 Startpage。
3. 瀏覽器設定如：地理資訊、鏡頭、和麥克風使用權限為「詢問」。
4. 優先使用瀏覽器服務以減少使用專屬桌面應用程式，降低隱私風險。
5. 在使用自動翻譯、文法檢查、AI 翻譯工具時，避免直接使用敏感資訊，用替代字串取代，例如：提及組織或是服務對象時，使用代稱或是 A、B、C…等代碼方式取代。
6. 勿直接開啟不明發件人寄來的電子郵件或附件，避免釣魚詐騙和惡意軟體的潛在威脅。
7. 在進行機敏議題搜尋或瀏覽時，啟用瀏覽器的無痕模式或私密瀏覽，以減少可追蹤的資料留下。
8. 在使用公共 Wi-Fi 或不安全的網路時，啟用 VPN 以加密資料數據流量，保護隱私。
9. 網站服務建立帳號後，如有支援二階段認證功能，請儘速完成二階段認證功能設定與啟用。
10. 透過密碼管理器提供的瀏覽器擴充套件自動帶入帳號、密碼資訊，請勿透過複製、貼上方式填入資訊，避免該頁面是為釣魚、假冒網站。（密碼管理器可以紀錄正確的網站網址並確認頁面為該網址才會列出可用帳號、密碼。）

## 安全建議執行

| 安全檢查               |                     優先等級                     | 說明細節                                                                                                                                                                                                                   |
| ---------------------- | :----------------------------------------------: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| VPN 連線               |  `優先`{style="background: red; color: white;"}  | 於公用網路使用 VPN 連線。                                                                                                                                                                                                  |
| 行動數據連線           |  `優先`{style="background: red; color: white;"}  | 於公共場域連線使用行動數據連線並透過傳輸線方式建立連線。                                                                                                                                                                   |
| 隱私瀏覽器             |  `優先`{style="background: red; color: white;"}  | 使用注重隱私的瀏覽器：Firefox, LibreWolf, Brave。                                                                                                                                                                          |
| 廣告追蹤               |  `優先`{style="background: red; color: white;"}  | uBlock Origin 套件阻擋第三方與廣告追蹤，請務必至少安裝此一套件在 Brave, LibreWolf, Firefox。                                                                                                                               |
| 地理資訊、鏡頭、麥克風 |  `優先`{style="background: red; color: white;"}  | 請將瀏覽器地理資訊、鏡頭、麥克風使用權限調整為「詢問」，當需要使用時才授權使用。                                                                                                                                           |
| 無痕視窗               |  `優先`{style="background: red; color: white;"}  | 使用無痕視窗是可避免瀏覽歷史資訊、cookies、快取等資料被儲存，但不可避免隱私或使用行為的追蹤（請與 VPN 搭配使用）。                                                                                                         |
| Chrome                 |    `須知`{style="background-color: #fff2cc;"}    | Google Chrome 會蒐集使用者行為來增進廣告對象的辨識能力。如需要使用與 Chrome 類似介面、但無隱私疑慮問題，可以改用 Brave。                                                                                                   |
| 在地提供網路           | `建議`{style="background: green; color: white;"} | 無法評估該地區或公用網路是否可靠，如其他因素必須連線，請記得全程與所有裝置開啟 VPN 連線。                                                                                                                                  |
| 搜尋引擎               | `建議`{style="background: green; color: white;"} | 使用注重隱私無追蹤的搜尋引擎：Brave Search、DuckDuckGo、SearXNG、Startpage。                                                                                                                                               |
| 自動翻譯               | `建議`{style="background: green; color: white;"} | 避免使用自動翻譯或文法檢查套件，如需輔助使用，請將可識別資訊或服務對象用任意字串取代後再使用。                                                                                                                             |
| Browser fingerprinting | `建議`{style="background: green; color: white;"} | 瞭解「Fingerprint」是目前還無法完全避免的追蹤方式，唯一可以努力的是做到與其他人看起來類似，不能看起來與其他人不一樣（獨特）。檢視自己的 Fingerprint 與相似性。                                                             |
| Cookies                | `建議`{style="background: green; color: white;"} | 定期清理 Cookies 不僅可以降低網站追蹤能力，近期也有相關新聞（2023/11/26）指出可透過復原已失效的 Cookie 接管帳戶的可能。也請同時檢查裝置授權的工作階段（Google 帳號設定、安全性、管理所有裝置，檢視與移除未使用裝置授權。） |
| 容器視窗               | `建議`{style="background: green; color: white;"} | 主要是區別工作、私人、特定目的的使用情境，可以透過建立多組使用者（Profiles）或透過容器分頁功能（Firefox Containers）隨用及丟的臨時容器（Temporary Containers）。                                                           |
| 桌面應用軟體           | `建議`{style="background: green; color: white;"} | 透過安全且注重隱私的瀏覽器使用服務，盡量不要使用桌面版本的應用程式。主要差異在透過瀏覽器可以統一限制安全與隱私保護範圍，透過專屬的桌面應用程式會有權限使用、隱私精準蒐集的問題。                                           |
