# 資安防護新手村 · Three.js 探險實驗

用 [Three.js](https://threejs.org/) 做的 3D 探險式學習遊戲雛形：
以**村莊**為基地，走出村莊探索荒野，尋找散落各地的「**資安遺跡**」——每一座遺跡 = 一門資安課程。靠近就會**發現**它、打開課程卡，點「閱讀」即連回正式站台 <https://ssd.ocf.tw> 對應章節，讀完即**點亮**。進度存在瀏覽器（localStorage），重開不會消失。

> ⚠️ 這是**獨立實驗**，自成一體：不依賴、也不影響其他文件內容；
> 只是放在 `docs/games/`、與文件一起被 build。章節名稱與連結僅作「素材」，連回正式站台。

## 怎麼跑（本機）

需用 HTTP 伺服器開啟（用了 ES module / importmap，直接 `file://` 開會被瀏覽器擋）。

```bash
cd docs/games
python3 -m http.server 8000          # 一般用法
# 或：python3 serve.py 8000          # 開發用（強制不快取，避免改檔後瀏覽器拿到舊版）
# 開瀏覽器 → http://127.0.0.1:8000/
```

手機測試：用 `python3 serve.py`，手機在同網路下開「電腦區網 IP:埠號」（如 http://192.168.0.10:8000）。改完檔重新整理即是最新版，不會被快取卡住。

免安裝、免建置；Three.js 由 CDN（jsDelivr，pin 在 `three@0.184.0`）載入，**第一次開啟需連網**。

小技巧：網址加上 `#<遺跡id>`（例如 `…/#personal`、`#org`、`#common`、`#guide`、`#tools`）會直接在該遺跡旁出生，方便分享特定課程。

## 與文件網站一起部署

本資料夾放在 `docs/games/`。`mkdocs build` 會把這裡的 html / js 原樣複製到 `site/games/`，
因此網站發佈後可在 **`/games/`（即 `games/index.html`）** 啟動遊戲，與其餘文件並存、不會進導覽。

- 這些檔案不是 `.md`，MkDocs 不會當成文件頁處理，只會原樣複製。
- 開發說明特意命名為 `README.txt`（非 `.md`），以免被 build 成多餘頁面。
- 驗證：`uv run mkdocs build` 後開 `site/games/index.html`。若站台啟用 minify / privacy 外掛，
  build 後請確認 importmap 與 JS 未被改寫；必要時把 `games/` 加入 `exclude_docs` 或外掛排除清單。

## 玩法循環

1. 在村莊中央先看**村長告示牌**（怎麼升級資安？）了解目標。
2. 從村口走出去，看右下**小地圖**：`?` 是還沒找到的遺跡。
3. 朝遺跡（遠方有**光束**指引）走過去，靠近就會**發現**，跳出課程卡。
4. 完成方式：
   - 每座遺跡都有**守關怪物**：點「⚔️ 挑戰守關怪物」進入戰鬥，用課程小問題回擊，**打贏才點亮**。
   - 也可先點「先閱讀章節備戰」連回 `ssd.ocf.tw` 研讀，再來挑戰。
5. 點亮全部遺跡，村子就安全了。

## 戰鬥（打怪 × 課程問答）

每座遺跡都有**守關怪物**（威脅的化身：釣魚巨怪、弱密碼史萊姆、勒索魔像、迷霧幽靈、資料蠹蟲，造型各異）。戰鬥是回合制問答：

- 怪物血量 = 題數；**答對**一題就出招扣血。
- 你有 3 顆**防護心**；**答錯**會失去一顆，並**揭曉正解與解說**（學習重點），接著點亮起的正解「學起來反擊」即可繼續。
- 怪血歸零 = **淨化成功**，遺跡點亮（完成）。
- 防護心歸零 = 先去讀章節再回來挑戰（可重來，不算失敗懲罰）。
- 每題解說都附**對應章節連結**，想深入就點進去。

> 設計原則：教育優先、不懲罰。答錯是學習點而非「Game Over」。
> ⚠️ 題目與解說屬資安教育內容，正式採用前請審閱正確性（集中在 `battles.js`）。

### 新增一場戰鬥

在 `battles.js` 的 `BATTLES` 物件，以遺跡 `id` 為鍵加入即可（沒加的遺跡維持「閱讀即完成」）：

```js
export const BATTLES = {
  personal: {
    monster: { name: '弱密碼史萊姆', emoji: '🦠', color: 0x6fb3a0, accent: 0x9affd1 },
    intro: '……',
    questions: [
      { q: '題目？', options: ['A','B','C','D'], correct: 2,
        why: '為什麼正解是對的……', link: 'https://ssd.ocf.tw/personal/' },
      // …更多題目
    ],
  },
};
```

## 檔案結構

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面外殼、HUD（標題/進度、任務清單、課程卡、小地圖、發現通知、載入畫面）、importmap |
| `content.js` | **內容素材**：村莊告示牌 + 各遺跡（標題、說明、子項目、座標、連結）。**要新增/調整主題改這裡就好。** |
| `battles.js` | **戰鬥內容**：守關怪物 + 課程小測驗題庫（以遺跡 id 為鍵）。**要加題目/加怪改這裡。** |
| `terrain.js` | 程序化地形高度函式（村莊壓平、外圍山脈、低處積水），供地形網格／角色行走／物件擺放共用 |
| `battle.js` | 戰鬥系統：3D 守關怪物、回合制問答、勝負處理、戰鬥運鏡 |
| `audio.js` | 音效：用 Web Audio API 即時合成（走路/開戰/出招/受擊/勝敗/發現），零外部音檔、含靜音開關 |
| `main.js` | 場景引擎：地形、植被（InstancedMesh）、村莊、遺跡、角色、鏡頭、控制、發現邏輯、進度（localStorage）、小地圖、串接戰鬥 |

## 想新增一座遺跡？

在 `content.js` 的 `RUINS` 陣列加一筆即可，例如：

```js
{
  id: 'incident-drill', title: '事件演練場', sub: '北方的訓練遺跡', emoji: '🎯',
  color: 0x66d9c2, style: 'tower', angle: 160, radius: 75,
  url: 'https://ssd.ocf.tw/common/phishing/',
  desc: '模擬釣魚信演練……', chips: ['辨識', '通報', '復原'],
}
```

`style` 可用：`grove`／`fortress`／`tower`／`obelisk`／`market`。

## 設計取捨

- **零資產管線**：所有模型都用 Three.js 基本幾何體拼出來，不需要 Blender 或外部貼圖，方便快速實驗與修改。
- **不綁架內容**：3D 世界只是「入口與動機」，真正教學仍在 MkDocs 文件，遺跡點「閱讀」後連回 `ssd.ocf.tw`。
- **大世界仍順**：地形 InstancedMesh 植被、單一方向光且陰影**跟著角色移動**、`pixelRatio` 上限 2。

## 可以再延伸

- 換上真正的 low-poly glTF 模型（Draco / KTX2 壓縮）提升質感
- 遺跡內的**小遊戲關卡**（例如釣魚信辨識），通關才算「閱讀完成」
- 徽章 / 成就、完成度回饋、夜晚與天氣
- 小星球（球面行走）版本，更接近 messenger.abeto.co 的視覺
- 多人連線（成本最高，教學非必要）
