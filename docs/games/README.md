# 資安防護新手村 · Three.js 探險

用 [Three.js](https://threejs.org/) 做的 **3D 探險式資安學習遊戲**。把 [ssd.ocf.tw](https://ssd.ocf.tw) 的資安教材包進一個小世界：以**村莊**為基地，走出去尋找散落荒野的「**資安遺跡**」——每一座遺跡都是一門資安課程。

> ⚠️ 這是**獨立實驗**，自成一體：不依賴、也不修改其他文件內容；只是放在 `docs/games/`、與文件一起被 build。章節名稱與連結僅作「素材」，閱讀時連回正式站台。

---

## 🎯 遊戲目的

這片土地曾被五道「資安防線」守護；防線一道道倒下後，村莊也跟著褪色、入夜。你的任務是：

1. **走出新手村**，找回散落荒野的**五座資安遺跡**（＝五門資安課程）。
2. 靠近遺跡就會**發現**它、跳出課程卡；點「閱讀」連回 `ssd.ocf.tw` 對應章節研讀。
3. 每座遺跡都有**守關怪物**——用課程裡學到的小知識在問答戰鬥中回擊，**打贏就點亮**遺跡、重建一道防線。
4. **五道防線齊備**，中央水晶重新綻放、天亮、村莊復甦——而這些好習慣，也能帶回你真實的數位生活。

設計原則：**教育優先、答錯不懲罰**。答錯只是學習點，不是 Game Over。進度存在瀏覽器（`localStorage`），重開不會消失。

### 暈 3D 怎麼辦（舒適模式）

landing 的「**晃動**」可選 **自動／減少／完整**（存 `localStorage`）。**自動**＝跟隨系統的「減少動態效果」（`prefers-reduced-motion`）設定。選「**減少**」後：

- 鏡頭跟隨與注視點的平滑再放慢，起始視角略高、略遠（地平線退到畫面上緣＝週邊光流變少）
- **移動時畫面四周漸暗**（移動暗角），停下就淡回全視野——遮掉週邊視野是最有效也最便宜的減暈手段
- 關掉雨天與閃電（螢幕空間雨絲的運動方向和世界對不上；閃電還會整屏調光）、亮部光暈減半
- 小地圖**固定北方朝上**、不再隨鏡頭轉；二段跳的旋轉特效轉慢並大幅淡化

另外有三項是**不分模式一律套用**的（原本就是手感問題，不該藏在開關後面）：鏡頭高度不再跟著走路的上下彈跳、鏡頭被地形抬起時改為平滑過渡（以前是硬夾會「彈」一下）、注視點跟鏡頭一樣有平滑（進戰鬥／終局運鏡不再瞬間扭頭）。**手機直向**另外會依畫面比例補回垂直 FOV（Hor+，上限 66°）——直向若固定用桌機的 52° 垂直 FOV，水平只剩約 25°，望遠鏡效應會把每次晃動都放大。

### 玩法循環

1. 在村莊中央看**村長告示牌**了解目標，找村中**法師**問路。
2. 走出村口，看右下**小地圖**：`?` 是還沒找到的遺跡；遠方有**光束**指引方向。
3. 朝遺跡走過去，靠近就**發現**、跳出課程卡。
4. **點亮遺跡的方式：**
   - 點「⚔️ 挑戰守關怪物」進入戰鬥，用課程小問題回擊，**打贏才點亮**。
   - 也可先點「先閱讀章節備戰」連回 `ssd.ocf.tw` 研讀，再回來挑戰。
5. **點亮全部五座**，村子就安全了，天也亮了。

### 戰鬥（打怪 × 課程問答）

每座遺跡的守關怪物是威脅的化身。戰鬥是**回合制問答**：

- 怪物血量 = 題數；**答對**一題就出招扣血；血歸零＝**淨化成功**、遺跡點亮。
- 你有 **3 顆防護心**；**答錯**會失去一顆，並**揭曉正解與解說**（學習重點），點亮的正解「學起來反擊」即可繼續。
- 防護心歸零 = 先去讀章節再回來挑戰（可重來，不算失敗懲罰）。
- 題型包含：選擇題、**釣魚信辨識**（二選一）、**網址識破**（找真網域）、**密碼強度**（即時輸入挑戰）。
- 每題解說都附**對應章節連結**，想深入就點進去。

> 設計原則：教育優先、不懲罰。答錯是學習點而非「Game Over」。
> ⚠️ 題目與解說屬資安教育內容，正式採用前請審閱正確性（集中在 `i18n/battles.js`）。

## 🛠️ 開發

### 怎麼跑（本機）

需用 HTTP 伺服器開啟（用了 ES module / importmap，直接 `file://` 開會被瀏覽器擋）。

```bash
cd docs/games
python3 -m http.server 8000          # 一般用法
# 或：python3 serve.py 8000          # 開發用（強制不快取，避免改檔後拿到舊版）
# 開瀏覽器 → http://127.0.0.1:8000/
```

手機測試：用 `python3 serve.py`，手機在同網路下開「電腦區網 IP:埠號」（如 `http://192.168.0.10:8000`）。

免安裝、免建置；Three.js 由 CDN（jsDelivr，pin 在 `three@0.184.0`）載入，**第一次開啟需連網**。

小技巧：網址加上 `#<遺跡id>`（`#personal`、`#org`、`#common`、`#guide`、`#tools`）會直接在該遺跡旁出生，方便分享特定課程。

探索模式：網址加上 `?explore=1`（或 landing 的「☀️ 白天自由探索」按鈕）直接以白天開場——只借「光」與白天內容（花海／海岸／釣魚台／拍照點／日之碎片），遺跡、維護者、大水晶等故事狀態照實呈現，課程任務照常可玩、全完成仍會觸發終局。右上「☀️ 探索模式」標籤點一下即回到故事模式。可與遺跡深連結並用（`?explore=1#tools`）。

### 展示模式（擺攤用）

網址加上 **`?attract=1`**：像街機的待機畫面——**自動開場**（不必有人點「開始探險」）→ 沒人操作就**自動巡遊五座遺跡**→ 繞完一圈再從頭，無限循環。

- **有人一碰就交還控制權**（鍵盤／點畫面／滾輪／虛擬搖桿都算），立刻變成正常遊玩；放手 **30 秒**沒動作，展示模式再自己接手。
- 隱含白天（等同 `?explore=1`）：展示要的是最亮、內容最多的狀態。
- 角色會停在距遺跡中心 6 的位置——遺跡本體碰撞半徑是 4、POI 觸發距離是 6.5，取中間值讓**課程卡會自己跳出來**，等於順便輪播教材內容。
- **主角頭上會冒出邀請泡泡**（「要不要一起來找資安遺跡？」「按任意鍵，就能接手喔！」等五句輪流，三語），在每次停下來展示時出現，招呼路過的人來玩。台詞在 `i18n/ui.js` 的 `attractInvites`。
- 進度存在**獨立的 `localStorage` key**，且每次開啟都清空：擺攤一整天不會污染正式存檔，也不會因為「全部發現過了」而展示不出初始樣貌。
- 卡住保護：走不到某站超過 30 秒就跳下一站，不會整晚停在原地。

參數集中在 `attract.js` 開頭的 `DEFAULTS`（停留秒數、鏡頭轉速、逾時）與 `main.js` 的 `ATTRACT_IDLE_MS`（放手多久後重新接管）。

> ⚠️ 現場注意：瀏覽器規定要有使用者手勢才能出聲，**自動開場的展示是靜音的**，直到有人碰過螢幕。要有聲音就得在開場時請人點一下。另外巡遊中角色持續移動＝一直維持 60fps，長時間擺攤請確認機器散熱。

### 與文件網站一起部署

本資料夾放在 `docs/games/`。`mkdocs build` 會把這裡的 html / js / 圖檔原樣複製到 `site/games/`，發佈後可在 **`/games/`** 啟動遊戲，與其餘文件並存、不會進導覽。

- 這些非 `.md` 檔，MkDocs 不會當文件頁處理，只會原樣複製。
- 本說明 **`README.md`** 已在 `mkdocs.yml` 的 `exclude_docs` 排除，**不會**被 build 成頁面（維持原本 `README.txt` 不被 build 的用意）；在 GitHub 上仍以 Markdown 呈現。
- `hooks/cache_bust.py` 會在 build 後替 `/games` 的 JS module 與圖檔加上內容雜湊版本號（`?v=…`），避免部署時新舊檔混搭載入失敗。
- 站台啟用了 `minify` / `privacy` 外掛；build 後可確認 importmap 與 JS 未被改寫。

### i18n 架構（三語）

`i18n/content.js`、`battles.js`、`ui.js` 都採「**結構與文字分離**」：語言無關的**結構**（id、座標、連結、style、題目正解索引…）獨立於一份基底，各語言只維護**文字字典**（`zh-Hant` / `zh-Hans` / `en`），再由 `assemble(lang)` 合併。譯者只改文字，不會動到座標或答案，避免改壞。**只有三個字典都備妥的語言才會出現在切換器**；未備妥者一律退回正體中文。

### 想新增一座遺跡？

在 `i18n/content.js` 的**結構**加一筆（`id`、`emoji`、`color`、`style`、`angle`、`radius`、`url`），並在**三個語言的文字字典**各補上對應文字（標題、副標、說明、關鍵字、提醒）。`style` 可用：`grove`／`fortress`／`tower`／`obelisk`／`market`。

### 想加一場戰鬥？

在 `i18n/battles.js` 以遺跡 `id` 為鍵，於**結構**加入怪物樣式與題目骨架（題型 `type`、正解索引 `correct`…），並在**三個語言**補上怪物名稱、題目與解說文字。沒加戰鬥的遺跡維持「閱讀即完成」。

### 想加一座白天支線站台？

支線站台是**白天限定**的獨立小遊戲（全清或探索模式才現身），把戰鬥裡練過的技能抽出來單獨練。要新增一種：

1. 在 `stations.js` 的 `Stations` 加一個 `_render<Game>(item)` 方法（照現有五種挑一種最接近的抄），並登記到 `_render()` 的分派表與 `TAKE`（每局題數）。互動結束一律呼叫 `this._verdict(ok, why)`，其餘（計分、下一題、結算、成就）都走共用流程。
2. 在 `i18n/stations.js` 以站別為鍵，於 `STRUCT` 放**語言無關的答案骨架**（網址真假、鎖的種類、`isFake`…），在 `TEXT` 三語各補文字。
3. 在 `i18n/ui.js` 三語的 `stations` 各補該站的介面字串（`title`／`start`／各站專屬按鈕與提示）。
4. 在 `main.js`：`STATION_DEFS` 加一筆（掛在哪座遺跡旁、寶珠色），並在 `ACHIEVEMENTS` 加一條成就、`ui.js` 的 `ach` 補文字。掛點、面板、碰撞、白天顯示都會自動跟上。

> ⚠️ 站台題目與解說屬資安教育素材，正式採用前請審閱正確性（內容集中在 `i18n/stations.js`）。

## 設計取捨

- **零資產管線**：所有模型都用 Three.js 基本幾何體拼出來，不需要 Blender 或外部貼圖，方便快速實驗與修改。
- **不綁架內容**：3D 世界只是「入口與動機」，真正教學仍在 MkDocs 文件，遺跡點「閱讀」後連回 `ssd.ocf.tw`。
- **大世界仍順、行動裝置不發燙**：地形 InstancedMesh 植被、單一方向光且陰影**跟著角色移動**、依裝置自動**分檔**（手機精簡省電、桌機精緻；可手動切換）。

## 可以再延伸

- 換上真正的 low-poly glTF 模型（Draco / KTX2 壓縮）提升質感
- 遺跡內的**小遊戲關卡**（例如釣魚信辨識），通關才算「閱讀完成」
- 徽章 / 成就、完成度回饋、天氣系統
- 小星球（球面行走）版本，更接近 messenger.abeto.co 的視覺
- 多人連線（成本最高，教學非必要）
