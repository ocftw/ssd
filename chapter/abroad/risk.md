# 出差風險評估

預計操作時間：約 10–15 分鐘（每次出差前評估一次）\
所需預算：無

出差前建議把可能遇到的風險逐一檢視，讓你/工作夥伴提前準備好對應的裝備。建議在確認出差行程後、**出發前 2 週**完成評估，並與組織同仁一起確認應對方式。

## 了解不同的風險

**政府監控與執法** 某些國家政府會監控、攔截通訊，或針對公民團體活動採取執法行動（拘留、罰款、驅逐）。

- **建議行動**：全程開啟 VPN，敏感通訊請使用 Signal 或加密電子郵件，不要在裝置上留下可能觸法的資料。
- **回看個人資安**：[VPN](https://ssd.ocf.tw/chapter/network/vpn.html)、[加密訊息對話](https://ssd.ocf.tw/chapter/e2ee/im.html)、[加密電子郵件](https://ssd.ocf.tw/chapter/e2ee/mails.html)

**政府監控與執法** 當地若存在示威、武裝衝突或高犯罪率，人身安全風險提高。

- **建議行動**：查詢[外交部旅遊警示分級表](https://www.boca.gov.tw/sp-trwa-list-1.html)確認燈號，擬定撤離路線並告知同仁。

**自然災害** 目的地是否處於地震帶、颱風季或洪災高風險區。

- **建議行動**：確認出差時間是否與當地災害季節重疊，出發前購買旅遊不便險與旅遊醫療保險。

**醫療資源** 當地醫院是否能處理突發狀況，醫療語言溝通是否有困難。

- **建議行動**：出發前購買含緊急後送的旅遊醫療保險，並備妥常備藥物與過敏藥品。

**傳染病** 目的地是否有特定傳染病（如瘧疾、登革熱）或入境要求。

- **建議行動**：查閱[疾管署旅遊疫情資訊](https://www.cdc.gov.tw/CountryEpidLevel/Index/NlUwZUNvckRWQ09CbDJkRVFjaExjUT09)，確認是否需要施打疫苗或攜帶預防藥物。

**個人資料與通訊被監控** 電信監控與 Wi-Fi 攔截在海外更常見，即使是自己租的 Wi-Fi 分享器也不能完全信任。

- **建議行動**：全程開啟 VPN，避免使用公共免費 Wi-Fi，不在不加密的通道傳送敏感資料。
- **回看個人資安**：[VPN](https://ssd.ocf.tw/chapter/network/vpn.html)、[瀏覽器](https://ssd.ocf.tw/chapter/network/browser_privacy.html)

**設備被入侵或植入惡意程式** 公共 USB 充電埠、惡意 Wi-Fi 熱點，都可能是設備被植入惡意程式的管道。

- **建議行動**：攜帶乾淨設備出差，使用自己的充電器（或 USB 充電資料隔離器），不使用公共 USB 充電埠。
- **回看個人資安**：[裝置物理防護](https://ssd.ocf.tw/user_guide/devices/index.html)

**交通事故** 當地道路狀況、交通規則與台灣落差大，或只有高風險交通工具可使用。

- **建議行動**：出發前了解當地主要交通工具，優先使用有信譽的租車或計程車服務。

**語言或文化誤解** 語言不通在緊急情況下可能造成溝通困難，文化差異也可能引發不必要的誤解。

- **建議行動**：準備常用緊急用語（紙本備份），確認有可聯繫的翻譯協助或當地可信聯絡人。

**欺詐或強迫行賄** 部分地區可能遇到索賄、詐騙或非正式費用要求。

- **建議行動**：出發前了解當地常見手法，攜帶少量現金備用，避免在索賄情況下使用主要信用卡。

## 評估出差風險

1. 針對目的地，逐一評估每項風險的「發生可能性」與「影響程度」，分別填入 1（低）、2（中）、3（高）。
1. 將兩個分數相乘得到「評分」（最高 9 分）。
1. **評分 6 分以上的項目，請在出發前確認已有對應準備**，可對照下方說明與[出差安全指南](https://ssd.ocf.tw/chapter/abroad/guide.html)採取行動。

| 風險因素                 | 發生可能性（1-3） | 影響程度（1-3） | 評分 |
| ------------------------ | ----------------- | --------------- | ---- |
| 政府監控與執法           |                   |                 |      |
| 社會動盪或暴力衝突       |                   |                 |      |
| 自然災害                 |                   |                 |      |
| 醫療資源是否充足         |                   |                 |      |
| 傳染病風險               |                   |                 |      |
| 個人資料與通訊被監控     |                   |                 |      |
| 設備被入侵或植入惡意程式 |                   |                 |      |
| 交通事故                 |                   |                 |      |
| 語言或文化誤解           |                   |                 |      |
| 欺詐或強迫行賄           |                   |                 |      |
