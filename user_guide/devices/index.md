# 裝置物理防護

預計操作時間：約 30 分鐘（研究選購，不含等待配送；安裝各配件約 10 分鐘）\
所需預算：視選購配件而定；基本款組合約 400–1,700 元，視訊鏡頭蓋可用便利貼替代（免費）

在開放辦公室、大眾運輸通勤或咖啡店工作時，身旁常有不特定人士，裝置也可能被他人短暫接觸。先把裝置的「物理環境」裝備好，能更安心使用手機、電腦。

可以增強的防護力

- 讓陌生人更不容易窺探
- 減少陌生人對裝置動手腳的機會

## 螢幕防窺片

螢幕防窺片是包覆在螢幕外層的貼膜或可拆卸片，裝上後從側面不易看到螢幕內容，適合在開放空間或通勤時使用，可降低旁人窺視取得重要資訊的風險。建議可考慮為筆電、平板或手機加裝。

- **尺寸與裝置相符**：\
  依螢幕尺寸選購，確保能完整覆蓋顯示區域。

- **防窺可視角度**：\
  角度越小、從側面越難看到內容；常見規格為左右各約 30 度（可視範圍約 60 度）。

- **透光度**：\
  建議不低於 80%，避免亮度不足增加眼睛負擔。

- **其他需求**：\
  防藍光、霧面或亮面、抗污等功能可依個人需求選購。

- 一般網路商場、3C商店皆有販售。

- 依尺寸與功能約 200–800 元，僅供參考。

## 視訊鏡頭蓋

許多應用程式會取得鏡頭權限，即便未在使用，仍可能被惡意程式或他人遠端開啟。視訊鏡頭蓋是覆蓋在筆電或平板前置鏡頭上的小蓋子或貼片，不用鏡頭時蓋上，可防止非預期開啟或監視，成本低、操作簡單。

- **厚度**：\
  確認不會影響筆記型電腦的開合。

- **外型**：\
  確定不會遮到環境光感測、麥克風等鏡頭周圍的東西。

- 一般網路商場都有販售，部分研討會攤位紀念品也可能會送。

- 多數約 50–200 元；或使用便利貼剪一小塊黏貼於鏡頭，0 元。

## USB 阻塞鎖

他人若隨意將 USB 裝置插入你的電腦，可能植入惡意程式或竊取資料。USB 阻塞鎖是插在未使用的 USB 或 Type-C 孔內的實體鎖，需特殊工具才能移除，可避免外出時被他人插入隨身碟等裝置。

- **孔位與規格**：確認與裝置的 USB-A 或 Type-C 孔位相符。

- **是否需常拔插**：若該孔經常要使用，可選可拆卸式；若長期不用，固定式即可。

- 購買前可確認是否需專用工具才能卸除，以達防護效果。

- 一般網路商場都有販售，部分研討會攤位紀念品也可能會送。

- 約 100–500 元，依規格與數量而定。

## 安全標籤與封條

在裝置接縫、螺絲或外殼黏貼安全標籤或封條，一旦被撕開或損毀，可立即察覺設備是否曾被他人動手腳。建議貼在不易注意到的位置（如螺絲處），並定期目視檢查是否破損。多為低單價，約 50–200 元可購得基本款。
